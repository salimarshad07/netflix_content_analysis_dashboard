# 🎬 Netflix Content Analysis Dashboard

## Overview
Interactive multi-page Tableau dashboard analyzing 
8,807 Netflix titles across Movies and TV Shows.

## 🔗 Live Dashboard
[View on Tableau Public](https://public.tableau.com/views/NetflixContentAnalysisDashboard_17790371616630/CountryInsights?:language=en-US&publish=yes&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)

## 📊 Dashboard Pages

### Page 1 — Overview
- Movies vs TV Shows split
- Content growth by year
- Top 10 Genres
- Rating Distribution
- KPI Cards: 8,807 Titles | 6,131 Movies | 
  2,676 TV Shows | 748 Countries

### Page 2 — Content Analysis
- Genre deep dive
- Rating breakdown
- Content trend by year

### Page 3 — Country Insights
- Interactive World Map
- Country-wise content distribution
- Top 10 producing countries

## 💡 Key Findings
- Movies dominate at 68% vs TV Shows 32%
- USA leads with 2,032 titles
- India is #2 with growing content
- Drama & International content is #1 genre
- Content additions peaked in 2019
- TV-MA is most common rating

## 🛠️ Tools Used
- Tableau Public
- Data: Kaggle Netflix Dataset (Shivam Bansal)
- 8,807 rows | 12 columns
